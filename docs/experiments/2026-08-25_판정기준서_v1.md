# 판정 기준서 v1 (Adjudication Codebook)

> 사전등록 §8.6b가 요구하는 과제별 판정 기준. 판정 프롬프트에 이 조항들이 그대로 삽입되며,
> 판정자는 **라벨 + 적용 조항 번호 + 근거 발췌** 3요소로만 답한다. 근거 없는 라벨은 무효.
> 예시는 파일럿(2026-08-21) 실측 사례다. 수정은 개정 이력로만 한다.
> 상태: **v1 초안** — 카나리아 세트 검증 전. 본실험 판정 전 확정 커밋 필요.

## 과제 A. FA 동치 — "최종 답변이 골드를 주장하는가"

**입력**: 질문, 골드(복수 가능), 최종 결론 발췌(§8.6 추출 규칙).
**출력**: `verdict ∈ {gold_asserted, other_asserted, abstain, gold_suspect}` + 조항 + 근거 발췌.

| 조항 | 규칙 |
|---|---|
| **A1. 결론만 판정** | 판정 대상은 답변이 **주장**하는 답이다. 언급≠주장 — 기각·비교하며 스친 답("일부 문서는 X라 하지만 답은 Y")에서 주장은 Y뿐이다. |
| **A2. 표기 변형 동치** | 대소문자·구두점·하이픈·서수·천단위 쉼표·날짜 형식·골드의 괄호 부가어는 무시한다. 예: "Jannik Sinner" ≡ "Jannik Sinner ( ITA )" ✅ |
| **A3. 고유명 철자 변형** | 같은 지시대상이 분명하면 1~2자 철자 차이는 동치. 예: "Marti Frederiksen" ≡ "Marti Fredericksen" ✅ (qacc-0404) |
| **A4. 수치** | 골드가 근사 표현("around 3000", "Over 60")이면 그 범위 해석에 부합하는 수치는 동치 — "3,028" ≡ "around 3000" ✅ (dragged-0069). 골드가 정확 수치면 정확 일치만 — "November 20" ≢ "November 27" ❌ |
| **A5. 패러프레이즈** | 의미가 같은 재서술은 동치. 예: "never officially given a proper name" ≡ "never given a name" ✅ (qacc-0067) |
| **A6. 부분 답** | 지시대상을 특정 못 하는 부분 문자열은 비동치 — "The Boy" ≢ "The Boy and the Heron" ❌ |
| **A7. any-gold** | 골드가 복수면 하나라도 주장했으면 gold_asserted. |
| **A8. abstain** | 확정 답 회피("문서에 없다", "판단 불가")는 abstain. 단 회피 표지와 함께 확정 답을 냈으면 그 답 기준(A1). 예: "not mentioned; the text only says…" → abstain 후보 (qacc-0365) |
| **A9. gold_suspect** | 답이 명백히 옳은데 골드가 틀려 보이면(오타·시점 문제) 라벨 대신 `gold_suspect` — 정오표 큐로. 예: 골드 "Boston Celti**s**", 답 "Boston Celtics" (dragged-0090) |

## 과제 B. L2 문장 스탠스 — "각 문장이 어느 문서에 어떤 입장인가"

**입력**: 트레이스(문장 번호 부여), 렌더링된 문서 텍스트. **골드 라벨은 비노출**(§8.4).
**출력**: 문장별 `{sent_id, doc_ref(있으면), stance ∈ {support, reject, neutral}}` 시퀀스 + 근거 발췌.
최종 L2 라벨은 판정자가 내지 않는다 — 시퀀스 위에서 규칙이 "마지막 명시적 지지"를 계산한다(§8.1).

| 조항 | 규칙 |
|---|---|
| **B1. 명시적 인용만** | `[Document k]`/"doc k" 등 문서를 특정한 문장만 doc_ref를 갖는다. 문서 불특정 진술은 neutral. |
| **B2. 같은 문장 귀속** | 지지/기각 표현은 같은 문장 안에서 인용된 문서에만 귀속한다. 앞뒤 문장의 동사를 끌어오지 않는다. 예: "Doc 3's '1885' is a scraping error. I will trust Doc 2." → Doc 3 reject, Doc 2 support (파일럿 실측 버그 사례) |
| **B3. 대조 구문 분리** | "ignore …, while Doc 2 is …" 같은 대조 절에서는 각 절의 술어를 그 절의 문서에만 귀속 (dragged 실측 사례) |
| **B4. 지지/기각의 정의** | support = 그 문서(의 답)를 채택·신뢰·최신·정확하다고 평가. reject = 구버전·오류·무관·기각. 평가 없는 재진술은 neutral. |
| **B5. 상충 평가 공존** | 한 문장이 같은 문서에 지지·기각을 함께 담으면 neutral로 두고 플래그 — 규칙이 아니라 사람 검수로 보낸다. |
| **B6. 가정·반사실 제외** | "만약 Doc 1이 맞다면…" 같은 가정 하의 평가는 stance가 아니다 → neutral. |

## 과제 C. L1 인정 (부가 축) — "트레이스가 문서 간 불일치를 인정했는가"

**출력**: `{yes, no}` + 근거 발췌. (본 라벨 축은 여전히 규칙 단서 기준 — 이 축은 κ 비교용 병행.)

| 조항 | 규칙 |
|---|---|
| **C1. 불일치의 정의** | 둘 이상의 문서가 **같은 질문에 다른 답/주장**을 준다는 명시적 진술. |
| **C2. 나열은 불인정** | 문서 내용을 병렬 요약만 하고 차이를 짚지 않으면 no. |
| **C3. 단서 어휘 불요** | "conflict" 같은 어휘가 없어도 실질(예: "Doc 1 says 1902 but Doc 3 says 1885")이면 yes. |

## 과제 D. stance (자기일관성 트랙) — "답변이 트레이스의 결론을 유지했는가"

**출력**: `{유지, 뒤집음, hedge}` + 근거. **전용 폼 사용** (과제 B 폼 재사용 금지 — 파일럿 버그).

| 조항 | 규칙 |
|---|---|
| **D1** | 트레이스의 최종 기울기와 답변의 주장(A1 기준)이 같으면 유지, 다르면 뒤집음. |
| **D2** | 답변이 양쪽을 대등 병기하면 hedge — 뒤집음이 아니다(사전등록 §1.8). |
| **D3** | 트레이스에 기울기가 없으면 판정 불가(무효) — 라벨을 지어내지 않는다. |

## 공통 출력 폼

```
label = <라벨>
criterion = <적용 조항, 복수면 쉼표>
evidence = "<입력에서 그대로 발췌한 근거, 40단어 이내>"
```

근거 발췌가 입력에 실제로 존재하지 않으면 판정 무효 → 재판정 1회 → 실패 시 사람 큐.

## 사람 검수 절차 (§8.6b-4)

1. 검수 시트 = 판정 시트 + `human_label`·`human_note` 빈 열. 검수자는 {라벨, 조항, 근거}를 보고 확인/정정.
2. 정정 시 `human_note`에 **잘못 적용된 조항 번호**를 기록 — 조항별 오류율이 기준서 개정의 근거가 된다.
3. 범위: 양성(AIR·Discordant)·불일치·gold_suspect 전수 + 일치 건 층화 표본(§3.5의 ~200건에 통합).
4. 판정자↔사람 κ를 과제별·조항별로 보고.
