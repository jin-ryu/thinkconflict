# ThinkConflict 사전등록 규약 (Preregistration)

> 이 문서는 실험 데이터를 생성하기 **전에** 라벨 규약·게이트 기준·해석 규칙을 못박는 사전등록이다.
> 커밋 타임스탬프가 "실험 전에 확정했다"의 물증이다. 실험 후 규약을 바꿔야 할 경우 기존 항목을
> 지우지 않고 문서 말미 **개정 이력**에 무엇을·왜 바꿨는지 남긴다.
> 각 조항의 근거·상세는 정본 계획서(`연구계획서_ThinkConflict.md`)의 해당 절을 §로 인용한다.
> 최초 등록일: 2026-07-10

## 1. 라벨 규약 (Labeling Protocol)

### 1.1. 3단계 라벨 정의 (§3.2.1)

| 단계 | 진단 질문 | 라벨 |
|---|---|---|
| **L1 탐지** | 문서 간 불일치를 감지했는가? | {detected, unrecognized} |
| **L2 해소** | 정답 지지 문서를 유효하다고 결론짓는 올바른 추론을 했는가? | {correct, wrong, unresolved} |
| **FA 표출** | 최종 텍스트에서 정답을 표출했는가? | {correct, wrong, abstain} |

부가 축 — 유형 인지: L1 = detected일 때 원인 유형(시간/오정보/관점)까지 짚었는가 {correct_type, surface_only}.

### 1.2. 결론 확정 규칙 (§3.2.1)
- L2 결론은 **트레이스 내 마지막 명시적 문서 지지**로 확정한다.
- 마지막까지 명시적 지지가 없으면 `unresolved`로 라벨한다. 암묵적 기울기(leaning)는 부가 라벨로만 기록하고(부록 A(c)2) L2 본 라벨에 합치지 않는다.
- 번복 횟수는 부가 신호로 기록한다(부록 B 연계).

### 1.3. 기권 분리 (§3.2.1)
- 확정 답을 내지 않은 `abstain`은 `wrong`과 구분하며, **AIR·오답률 분모에서 제외**하고 별도 기권율로 보고한다.
- 완화 기법이 L2 = correct 문항의 기권 유도로 AIR을 인위적으로 낮추는 경로를 차단하기 위해, **환경 간 기권율 차이를 AIR과 나란히 의무 보고**한다(Reflection 환경에서 특히 점검).
- 흐름 행렬(전→후)의 상태 공간에 기권을 명시적 상태로 포함하고, 정상 경로→기권 이동은 '퇴행-기권' 하위 항목으로 집계한다(§3.3.2).

### 1.4. 동치 채점 (§3.2.1)
- FA의 `correct`는 답변 정규화(별칭·수치·날짜 형식 통일) + 동치 판정을 거친 **정확도(accuracy)** 다. 엄밀 문자열 EM이 아니다(표기 노이즈가 AIR로 새는 것 방지).
- 계획서에서 'EM'으로 약칭한 표면 지표는 전부 이 동치 판정 기반 정확도를 뜻한다.

### 1.5. 다중 정답 (any-gold) (§3.1.2)
- RAMDocs처럼 유효 정답이 복수인 문항의 L2·FA `correct`는 **정답 집합 중 어느 하나를 지지·표출한 경우**로 정의한다.

### 1.6. 4경로 분해 — 상호배타·전수 (§3.2.2(1))
정답(FA = correct)은 아래 네 경로 중 정확히 하나에 귀속된다.

| 경로 | L1 | L2 |
|---|---|---|
| 정상 (Legitimate) | detected | correct |
| Shortcut | detected | unresolved |
| Discordant Hit | detected | wrong |
| Blind-Hit | unrecognized | — |

### 1.7. 단계별 손실 지표와 분모 병기 (§3.2.2(2))
- Loss_L1 = P(L1 = unrecognized), Loss_L2 = P(L2 ≠ correct | L1 = detected), **AIR** = P(FA = wrong | L1 = detected, L2 = correct, 비기권).
- 조건부 지표는 항상 **결합확률과 분모 N을 함께 보고**한다(부분모집단 차이로 인한 오도 방지).
- Loss_L1은 **"언어화된 인지 실패율"** 로 명명한다. 유도 프로브 결과(침묵 상한/무능 하한 분해)는 Loss_L1 값 자체를 바꾸지 않으며 참고용으로만 병기한다(부록 A(c)1).

### 1.8. 이중 트랙 (§3.2.2(2) 측정 기준점)
- **행동(정확도·AIR) 트랙**: 채점 가능한 사실 충돌에 한정.
- **자기일관성 트랙**: 명시적 상충 전체로 확장. 답변 입장 라벨은 {유지, 뒤집음, 균형 병기(hedge)} 3분류 — 트레이스가 기울었는데 답변이 병기하면 불일치가 아니라 **hedge로 별도 집계**한다.

## 2. 검정력·보고 규칙 (§3.2.3)

1. **유효 분모 N < 20인 셀은 점추정과 CI만 제시하고 환경·모델 간 비교 주장을 세우지 않는다.**
2. 비교 주장은 QACC 게이트 통과분·RAMDocs(500)로 분모를 확보한 위에서 수행하고, DRAGged 자연 사실 충돌(채점 가능 56~61건)은 방향 일치 확인용으로 쓴다.
3. **세 데이터셋은 풀링하지 않고 분리 보고**한다(충돌 정의·문서 수·길이·메타데이터 가용성 상이).
4. 시드 반복(≥5)은 문항 분산을 줄이지 못하므로 **문항 부트스트랩을 항상 병행**한다(Paired Bootstrap 95% CI).
5. 흐름 지표는 문항별 **시드 다수결 경로** 위에서 정의하고, 다수결 과반 미달 문항은 **불안정 플래그**로 분리 집계하며 시드 간 경로 일치도(모드 비율)를 보고한다(§3.3.2).
6. LGR 분모("baseline 오답 ∧ 완화 후 정답")가 기법별 20 미만이면 **기법 pooled LGR**(기법별 점추정 병기)로 대체 보고한다.

## 3. 게이트 (실험 진행 조건)

### 3.1. 유효 충돌 게이트 (Phase 1 산출물 검증)
- 공통 스키마 문항이 채점 트랙에 들어가려면 **정답 지지 문서와 충돌(반대 입장) 문서가 공존**해야 한다. 통과율과 데이터셋별 최종 N을 확정해 검정력 표(§3.2.3)를 갱신한다.

### 3.2. DRAGged 골드 매핑 규칙 (§3.1.1(4))
- 정답 문서 자동 매핑(문자열+NLI)은 1차 초안이며, 행동 주장이 걸린 사실 충돌 문항은 **전수 인간 검증·교정한 골드 매핑**을 쓴다(정답 정오표 교정 포함).
- **복수 매칭은 제외 사유가 아니라 해소 대상**: 매칭 문서 중 `date` 최신성(+정답 지지)으로 유효 문서를 선정한다. 날짜 동률·부재로 해소 불가한 문항과 무매칭 문항만 플래그하여 L2 의존 지표에서 제외하고 건수를 보고한다.

### 3.3. QACC 스크리닝 게이트 (§3.1.3(4)) — 투입 전 필수
① sharp/soft 재분류(LLM 판정자 2종 + 인간 스팟체크; sharp만 채점 트랙 투입) ② DRAGged 질문 중복 47건 제거(판정 불일치 27건은 경계 사례로 보고) ③ `correctAnswer` 재검증 ④ 문서 길이 공변량 기록(스니펫 한계 통제) ⑤ 셔플링·표준 렌더링.
- 유료 API 판정자는 **비용 예측·승인 후에만 집행**한다(부록 D).

### 3.4. go/no-go — 전면 마스킹 게이트 (Phase 2, §3.3.3(b))
- `<think>` 전체 마스킹 시 답 분포가 유의하게 달라지지 않으면 사고 채널이 답과 무관한 장식이므로, **사고-답변 진단 자체를 중단하고 재설계**한다.

### 3.5. 라벨 신뢰도 게이트 (§3.2.1, 부록 A)
- 판정자는 대상 모델과 **다른 계열** 2종(오픈 1 + 상용 1), 옵션 순서 무작위 스왑, 형식-채움 프로토콜.
- 인간 2인 검증: **AIR·Discordant Hit 양성 전수 + 나머지 셀 층화 표본(합계 ~200건)**.
- L2 라벨 κ < 0.7이면 라벨 정의를 수정해 **재라벨링 루프**를 돈다. 판정자 불일치 문항은 인간 adjudication으로 확정한다.

### 3.6. 치환 증강 트랙 게이트 (부록 C, 예비)
- 자연 사실 충돌과 증강 표본의 Loss_L1 분포가 유사한 **난이도 동등성**을 확인한 뒤에만 본 실험(RQ3 세 번째 매칭 근거)에 투입한다. 시간형 변형은 본문 시제·정황 단서 정합까지 검수한다.

## 4. 인과 해석 규칙 (§3.3.4)

- **인과 기여 = 절단 효과 − 자연 종료점(no-op) 효과**로 정의한다.
- **filler-token 대조로 형식 교란의 상한을 확인한 위에서만** ΔAccuracy를 사고의 인과 기여로 해석한다.
- 인과 주장은 개입 실험(truncation·on-policy resampling)에 한정하며, 텍스트 관측(AIR 등)으로 인과를 주장하지 않는다(§1.3 L-a/L-b 경계).
- resampling 지점(L2 문장) 국소화는 판정자 의존이므로 인접 문장 다지점에서 함께 재생성해 국소화 잡음을 완충한다.

## 5. 결과 커밋 규칙 (§5 git 전략)

- `results/` 집계 산출물은 생성 즉시 커밋해 지표 계산 시점을 남긴다(raw 생성물은 git 미포함).
- 규약 개정은 삭제 없이 아래 개정 이력에 추가한다.

## 6. 자원 축소 우선순위 (부록 D, 사전 선언)

자원 부족 시: ① 보강층 축소(부록 B 상관 분석·유형 인지) → ② 완화 환경 5→3개(디코딩 1 + 프롬프트 1 + 대조군) → ③ 시드 5→3(CI 병기 유지). **주력(완화 회계)과 검증(RQ3 대조군·RQ4 개입)은 사수**한다.
