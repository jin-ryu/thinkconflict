# 종합: 방법론 비교, 공통 공백, 신규 논문 주제

논문별 상세 분석은 `01_*.md` ~ `07_*.md` 참조.

## 1. 방법론·한계 비교표

| 논문 | 접근 방법론 | 핵심 한계 |
|---|---|---|
| **Tug-of-War** (LREC-COLING 2024) | 내부 기억 vs 외부 근거 충돌을 인지편향 4종(Dunning-Kruger, availability, majority rule, confirmation)으로 진단하고, 내부/외부 로짓을 대조하는 CD² 디코딩 제안 | ChatGPT로 생성한 인공 충돌 데이터, 토큰 겹침 지표만 사용, abstention 능력 미측정, 블랙박스 모델 적용 불가, 내부 기억이 옳을 때의 부작용 미검증 |
| **COIECD** (ACL 2024) | 토큰별 정보량-엔트로피 시프트로 충돌 여부를 판별한 뒤 충돌/비충돌 토큰에 다른 디코딩 적용 | 충돌 라벨이 "모델이 틀린 문제"와 동치라 순환적, 충돌 판별기 자체의 정밀도/재현율 미측정, 전체 로짓 필요(API 모델 불가), pre-2024 base 모델에서만 검증, 컨텍스트가 틀린 경우 오류 강화 |
| **Self-RAG** (ICLR 2024) | reflection token(Retrieve/IsRel/IsSup/IsUse)을 학습해 검색 시점·문서 유용성·근거 지지를 자기비평, 세그먼트 빔서치 | 문서를 1개씩 독립 처리해 문서 간 모순 관측 불가, IsSup이 "무지지"와 "반박"을 병합, 충돌 해소가 승자독식 argmax, 자기지지적 날조 문서에 취약 |
| **RAMDocs / MADAM-RAG** (COLM 2025) | 모호성+오정보+노이즈+근거 불균형 동시 벤치마크와 문서 1개당 에이전트 1개의 다라운드 토론 | 오정보가 entity-swap 단일 전략, 출처 메타데이터·시간축 전무, all-or-nothing EM, 동일 예산 베이스라인 부재, multi-hop 결합 근거 구조적 불가 |
| **ConflictRAG** (투고 중) | 2단계 충돌 탐지(MLP+LLM) → 유형 분류 → Entropy-TOPSIS 출처 평가 → 충돌 인지 생성 | pairwise 판정만 있고 전역 통합 절차 부재, 합성 충돌의 문체 아티팩트 학습 위험, authority를 LLM 사전지식으로 추정(순환), CARS 지표의 자기 유리 설계 |
| **Conflict-Aware RAG** (WWW '26) | perplexity 격차 기반 ConScore를 SFT→DPO→Reranking 전체에 주입, 외부 API 없이 자기 신호만 사용 | PPL 격차 = 충돌 전제 미검증, 모델이 원래 모르는 영역 개선 불가, 시간적 충돌 미통제, EM/F1만 평가 |
| **FaithfulRAG** (ACL) | 내부 지식을 fact 단위로 외재화해 컨텍스트와 정렬 후 구조화 Self-Think로 충돌 해소, 무학습 | 성능 대부분이 구조화 CoT에서 나오고 self-fact 기여는 1~2%p, 정렬이 유사도 기반이라 모순 탐지가 아님, 문서 간 충돌 미처리, 질의당 4~5회 호출 비용 미보고 |

## 2. 문헌 전체를 관통하는 공백 (교집합)

1. **충돌 데이터의 인공성**: 전부 entity-swap 또는 LLM 생성 반사실 문서. 자연 발생 충돌(뉴스 정정, 위키 편집 이력, 가이드라인 개정)로 만든 벤치마크가 없다.
2. **시간축·출처 메타데이터 부재**: 발행일, 도메인 권위, 인용 관계를 가진 데이터셋이 한 편도 없다. "최신 vs 다수결 vs 권위"가 충돌하는 현실 시나리오가 통째로 빠져 있다.
3. **abstention·충돌 표출 평가 부재**: 모든 논문이 정답 맞히기(EM/F1/Recall)로만 평가. "출처들이 상충하므로 A와 B 두 견해가 있다"고 말하는 능력, calibration, 유보 품질을 재는 지표가 없다.
4. **충돌 탐지기 자체의 검증 부재**: COIECD의 엔트로피 게이팅, Conflict-Aware RAG의 ConScore 모두 다운스트림 성능으로만 간접 평가. 탐지 신호가 실제 사실적 모순과 상관하는지 직접 잰 논문이 없다.
5. **n-ary 충돌의 전역 해소 부재**: Self-RAG는 문서 1개씩, ConflictRAG는 pairwise, MADAM-RAG는 결합 근거 불가. 3개 이상 문서가 얽힌 충돌 집합을 일관되게 통합하는 정식화가 없다.
6. **비용 통제 비교 부재**: FaithfulRAG(5회 호출), MADAM-RAG(문서 수×라운드), ConflictRAG(pairwise 10회) 모두 동일 토큰 예산의 self-consistency 베이스라인과 비교하지 않았다.
7. **적대적 관점 부재**: "자기 주장을 완벽히 지지하는 날조 문서"는 IsSup·ConScore·TOPSIS 모두에서 오히려 유리해진다. poisoning 방어를 다룬 논문이 없다.

## 3. 신규 논문 주제 리스트 (추천 순)

### A. 충돌 탐지 신호의 타당성 검증 + 스팬 수준 충돌 벤치마크 (진단/벤치마크)
- 해결하는 공백: 4 (COIECD·ConScore·엔트로피 신호 전부 미검증)
- 내용: 인간이 토큰/스팬 단위로 충돌 라벨을 부여한 데이터셋을 만들고, 기존 신호들(엔트로피 시프트, PPL 격차, NLI, self-fact 유사도)의 precision/recall/AUC를 직접 측정. "기존 기법들이 재는 것은 충돌이 아니라 지식 부재/무관련성"임을 실증하면 그 자체로 강한 비판 논문.
- 장점: 학습 인프라 없이 평가 설계만으로 성립, 기존 7편 중 4편을 직접 반박하는 포지셔닝 가능.

### B. Abstention-aware 충돌 처리: "정답 맞히기"에서 "충돌 보고하기"로 (평가 프로토콜 + 기법)
- 해결하는 공백: 3
- 내용: 충돌 상황의 바람직한 행동을 {한쪽 채택 / 양쪽 병기 / 유보}의 3방향 정책으로 정의하고, conflict recall(존재하는 모순 근거 언급률), cherry-picking rate, risk-coverage 지표를 제안. 기존 기법들(CAD, COIECD, FaithfulRAG, MADAM-RAG)을 이 축에서 재평가하면 순위가 뒤집힐 가능성이 높다.
- 장점: 현재 리포지토리의 composite conflict 연구(직접 판정 파이프라인)와 방법적으로 이어진다.

### C. 출처 메타데이터·시간축을 갖춘 자연 발생 충돌 벤치마크 (데이터셋)
- 해결하는 공백: 1, 2
- 내용: 위키 revision history, 뉴스 정정, 가이드라인 개정에서 수집한 in-the-wild 충돌에 발행일·도메인·복제 구조(동일 주장의 에코체임버) 메타데이터를 부착. 핵심 실험은 "합성 충돌로 학습한 탐지기가 자연 충돌로 전이되는가". RAMDocs가 비워둔 가장 큰 칸.
- 단점: 데이터 수집·주석 비용이 크다.

### D. n-ary 충돌의 전역 해소: 충돌 그래프 기반 집계 (기법)
- 해결하는 공백: 5
- 내용: pairwise NLI 판정을 signed graph로 보고 correlation clustering이나 argumentation framework로 일관된 주장 집합을 추출한 뒤 생성에 전달. Self-RAG의 독립 처리, ConflictRAG의 pairwise 한계, MADAM-RAG의 결합 근거 불가를 동시에 겨냥.

### E. 충돌 신호의 적대적 취약성: self-supporting 날조 문서 공격과 방어 (보안/강건성)
- 해결하는 공백: 7
- 내용: IsSup·ConScore·TOPSIS가 "자기 주장을 잘 지지하는 문서"를 선호한다는 구조적 약점을 공격으로 정식화(소수 문서로 다수결을 뒤집는 비용 곡선 포함)하고, 출처 독립 신호 기반 방어를 제안.

### F. 블랙박스 모델용 충돌 게이팅 (실용 기법)
- 해결하는 공백: CD²·COIECD의 로짓 접근 전제
- 내용: top-k logprobs 절단 근사 또는 소형 프록시 모델로 게이팅 신호만 계산해 대형 API 모델에 적용. Tug-of-War 저자들이 명시적으로 남긴 미해결 문제라 포지셔닝이 쉽다.

### G. 동일 예산 하 충돌 파이프라인 재평가 (메타/분석)
- 해결하는 공백: 6
- 내용: FaithfulRAG, MADAM-RAG, ConflictRAG를 동일 토큰 예산의 self-consistency·long-context 단일 추론과 비교해 "구조의 기여분"을 분리. 결과가 어느 쪽이든 논문이 된다.

## 4. 추천

**A 또는 B** (또는 A+B를 묶은 "충돌 탐지·표출 능력의 진단 벤치마크"). 근거는 세 가지:
1. 기존 7편의 검증되지 않은 전제를 정면으로 치는 비판적 포지셔닝이 가능하다.
2. 대규모 학습 없이 평가 설계 중심으로 성립한다.
3. 진행 중인 composite conflict 연구의 판정 파이프라인 자산을 재활용할 수 있다.
